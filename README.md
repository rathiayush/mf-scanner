# Mutual Fund Scanner

A comprehensive system for scanning, processing, and analyzing mutual fund portfolio files.

## Architecture

- **Frontend**: React with Ant Design
- **Backend**: .NET Core Web API
- **Database**: SQL Server / Entity Framework Core
- **File Processing**: Excel file parsing with multiple format support

## Features

- 📂 Automatic folder scanning for mutual fund portfolios
- 📊 Excel file processing with format normalization
- 🔍 Duplicate file detection
- 📝 Comprehensive logging system
- 🎯 Real-time file monitoring
- 📈 Portfolio analysis and reporting

## Project Structure

```
mf-scanner/
├── backend/                 # .NET Core API
├── frontend/               # React Ant Design app
├── memory/                 # Technical documentation and strategies
├── database/              # Database scripts and migrations
└── docs/                  # Project documentation
```

1. Clone the repository

3. Set up the frontend app (see frontend/README.md)
